## Description
Glowria is an online beauty and cosmetics store inspired by platforms like Sephora. It allows users to browse products by category, view product details  The app provides a seamless shopping experience with features like search and user authentication.


## Functionality:
- Add, edit, or delete products (admin functionality).

- View detailed product information
